To add your professional photo:
1. Put your image in assets/
2. Name it profile.jpg
3. Replace the .portrait-placeholder block in index.html with:
   <img src="assets/profile.jpg" alt="Sachin Kumar Jha">

This is a plain static website. No npm, React, or build step is required.
It can be opened directly by double-clicking index.html and can be deployed directly to Vercel.
